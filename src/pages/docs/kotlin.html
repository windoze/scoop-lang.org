对比 Kotlin

Scoop 尽量兼容 Kotlin 的核心语法：类、接口、object、扩展函数、lambda、默认/命名参数、运算符重载、when、异常与 suspend 都按你熟悉的方式工作。本页列出 Kotlin 开发者最需要注意的差异。

Option 而非 null

?.、?:、!!、as? 都保留，但底层是普通 enum。构造可空值时需要写 Some(x) 或 None：

val nickname: String? = Some("Ada")   // 不能直接写 "Ada"
val absent: String? = None             // 没有 null 字面量
println(nickname ?: "guest")

对 Option 判空之后不会 smart cast 成 T，请用 when 解构、?: 或 !! 取值。因为可空不会合并，若 f() 返回 R?，则 a?.f() 的类型是 R??。

值类型

struct、enum 和 tuple 没有 identity：对它们使用 === 是编译错误，== 是自动派生的逐字段比较。struct 字段只能是 val，没有 init 块；修改通过副本更新得到新值：

struct Config(val host: String, val port: Int = 8080)

val base = Config("localhost")
val prod = base.{ host: "example.com", port: 443 }

struct 的副本更新与位置解构是内建语法，不通过 Kotlin 的 copy() 或 componentN() 方法实现；也没有 Config { … } 形式的结构体字面量。值类型转为接口或 Any 时自动装箱，但数组字面量这类批量位置不会自动装箱，需要显式 as。

when 与 case

普通分支保持 Kotlin 语义；只有以 case 开头的分支才是模式。每个 case 只有一个模式，不支持用逗号并列多个模式：

fun label(value: (Int, String?)): String = when (value) {
    case (0, _) -> "zero"
    case (n, Some(name)) if n > 0 -> f"${name} #${n}"
    case (_, Some(_)) -> "negative"
    case (_, None) -> "anonymous"
}

模式中的裸标识符总是新的绑定（除非它是 subject 所属 enum 的变体名）；要和已有常量比较，请使用 guard。

闭包与 lambda

  • 闭包只能捕获 val、参数和 this，读写外层局部 var 都会报错；需要共享可变状态时显式捕获一个引用对象并修改它的属性；
  • 捕获在创建时按值发生：值类型被完整复制进闭包环境；
  • lambda 中不能写裸 return 跳出外层函数；
  • inline、noinline、crossinline、reified、tailrec 为了兼容而被接受，但解析后完全忽略，不改变任何语义。

泛型

  • 所有类型参数都是不变的，List<String> 不是 List<Any>；需要转换时显式 map 或重新构造；
  • 类型位置必须写全类型实参，没有裸泛型类型和 star projection；
  • 调用处可以用 _ 部分推断：Pair<_, String>(first, second)；
  • 没有隐式的 Self 类型，接口契约用显式类型参数表达，例如 Equals<T>、Compare<T>；
  • 接口方法和可覆写的虚方法不能声明自己的类型参数。

相等、字符串化与哈希

Any 没有任何成员。== 只决议左侧静态类型上的 operator fun equals，Any == Any 是编译错误。println 的签名是 fun <T : ToString> println(v: T)，因此打印自定义类型需要显式实现 ToString：

struct Point(val x: Int, val y: Int) : ToString, Hash {
    public override fun toString(): String = f"(${x}, ${y})"
    public override fun hash(): Long = x.hash() * 31L + y.hash()
}

注意覆写 public 接口成员时要写 public override，因为 Scoop 的默认可见性是 internal。

数值

  • Int/UInt 固定 32 位，Long/ULong 固定 64 位，另有 8/16 位整数；
  • 二元运算要求两侧类型相同，字面量会按期望类型适配；不同类型需显式转换；
  • 溢出回绕，compareTo 返回 Long；
  • 数组、字符串和集合的长度、下标使用 Long：array[0L]、text.charLength。

不包含的 Kotlin 特性

  • 多平台：expect / actual；
  • JVM 互操作：@JvmStatic、@Throws 等注解，SAM 转换、平台类型 T!；
  • external 声明（改用 @Extern）；
  • 运行期反射与 ::class 反射 API；
  • data class、enum class、inline/value class；
  • null 字面量及普通字符串的 $ 插值。

Scoop 新增的能力

  • 值类型、副本更新、嵌套解构与穷尽的模式匹配；
  • 单态化泛型，以及条件接口实现、负向约束等泛型约束；
  • 编译期合成的编解码（ValueEncoder / ValueDecoder）与静态类型描述；
  • 直接的 C FFI：@Extern、@CLayout、Ptr、FunPtr、@Unsafe、@NoGC；
  • 确定性资源释放：同步关闭用 Closeable + use，异步关闭用 AsyncCloseable + useAsync；一般资源保留 Disposable.dispose()。GC-free 的 release 块只提供尽力而为的回收清理；
  • task-local 的上下文参数 context(name: T)，在协程与任务之间按规则传播；
  • 编译到原生可执行文件，无需虚拟机。
