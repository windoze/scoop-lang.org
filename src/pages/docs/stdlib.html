标准库

Scoop 工具链附带一组预编译的库 Cone，覆盖从集合、文本到 TLS、HTTP/2 与终端交互的常见需求。它们都是普通的 Scoop Cone：源码随安装包发布在 ~/.scoop/src，每个库都有可运行的 examples/，完整 API 见 API 文档。

使用内置库

内置库的 group 都是 scoop，当前版本为 0.1.0。scoop.core 总是可用；单文件程序还默认依赖 scoop.std。其他库需要显式声明：

Cone.toml
[dependencies]
"scoop:scoop.std" = "=0.1.0"
"scoop:scoop.json" = "=0.1.0"
"scoop:scoop.http.server" = "=0.1.0"

单文件程序则在文件头写 //! dep: scoop:scoop.json:0.1.0。依赖本身不会导入名称，仍需 import 对应的包。

核心与基础库

Cone内容
scoop.core语言所需的最小核心：基本类型、String、StringBuilder、Option、数组与 ArrayList、区间与迭代、异常、Equals/Hash/ToString/Compare 等运算符接口、协程原语与结构化并发、原子类型、Ptr/FunPtr 等 FFI 类型、编解码协议与 typeInfo。默认导入 prelude。
scoop.std平台无关的基础库：scoop.collections（List/Map/Set、HashMap、LinkedHashMap、TreeMap、ArrayDeque、PriorityQueue、排序与集合运算）、scoop.text（查找、分割、替换、数值解析与格式化）、scoop.bytes、scoop.io.encoding（Base64、Hex）、scoop.time / scoop.datetime、scoop.random、scoop.uuid。
scoop.math八种整数的受检算术、Float/Double 数学函数、不可变 BigInteger / BigDecimal，以及值类型 MathContext / RoundingMode。
scoop.test测试库：@Test 声明、断言、预期异常、前后置钩子，由 scoop test 驱动。

平台与异步 I/O

Cone内容
scoop.platform同步平台 API：文件系统、目录、临时文件、环境变量、进程、线程与并发原语、网络、系统时钟与系统熵、native I/O buffer。
scoop.asyncio平台事件循环 PlatformEventLoop：macOS 使用系统 libdispatch，Linux 使用 io_uring/liburing；提供定时器、TCP/UDP、DNS、异步文件与目录、TTY、SOCKS5，复用 core 的 Job、CoroutineScope、async/launch 与取消协议。
{{example coroutines}}

PlatformEventLoop.run 是同步、单次使用的根入口，等待根作用域和子任务完成，并关闭本轮遗留资源。Linux 异步后端要求内核 6.1 及实际可用的 io_uring 能力；初始化会探测所需操作，能力不足时报错，不自动切换后端。

已有宿主主循环的程序可使用 PlatformEventLoop.attach，由宿主监听通知并推进任务；macOS 提供 MainDispatchHost。具体生命周期和线程规则见异步 I/O 规范。

网络与安全

Cone内容
scoop.http内存中的 HTTP 协议库：HTTP/1.x（llhttp）与 HTTP/2（nghttp2）编解码、头部与消息模型、SSE、NDJSON、multipart、AWS EventStream、公共后缀表。不涉及 socket。
scoop.http.asyncio在任意异步字节流上运行 HTTP 传输，连接与 TLS 由调用者提供。
scoop.http.client统一的 HTTP/1.x / HTTP/2 客户端：连接池、认证、代理、缓存、下载、SSE 与 WebSocket，类型化 JSON 请求与响应。
scoop.http.server纯 Scoop 的应用层 HTTP 服务器：显式路由、middleware、JSON、SSE、静态文件与 SPA、优雅关闭；不使用反射或 DI 容器。
scoop.tls / scoop.tls.asyncio基于 OpenSSL 的同步与异步 TLS：客户端/服务端、证书与信任配置、ALPN。
scoop.crypto摘要（SHA-256 等）、增量摘要、HMAC、对称加密、签名、X.509 与 JWS。
scoop.urlURI/IRI 解析、相对引用、组件拼装、百分号编码与表单 codec。
scoop.idna国际化域名（UTS #46）与 Punycode。

一个带 JSON 请求与响应的 HTTP 服务只需要几十行：

{{example http_server nooutput}}

在一个终端启动服务：

$ scoop run --release http_server.scoop

在另一个终端请求两个端点：

$ curl 'http://127.0.0.1:8080/greet?name=Scoop'
{"message":"Hello, Scoop!"}
$ curl -X POST -H 'content-type: application/json' -d '{"name":"Ada"}' http://127.0.0.1:8080/greet
{"message":"Hello, Ada!"}

演示结束后，在运行服务的终端按 Ctrl+C 停止程序。

数据、文本与编码

Cone内容
scoop.json严格 JSON 解析与生成、不可变值树、基于 ValueEncoder/ValueDecoder 的类型化编解码。
scoop.regex基于 PCRE2（启用 JIT）的 UTF-8 正则：编号/命名捕获、惰性搜索、替换与分割。
scoop.charset字符集严格/有损转码、NFC 规范化、字素簇分段。
scoop.compressiongzip、zlib、raw DEFLATE、Brotli 与 zstd；内存、增量、同步流与异步流共用一套 API。

应用开发与终端

Cone内容
scoop.cli声明式命令行解析：用注解描述位置参数、选项与开关，自动生成帮助。
scoop.log日志 facade：库创建分类 Logger，应用选择 provider；消息惰性求值。
scoop.log.console同步的 stdout/stderr 日志 provider，支持级别、格式与源码位置。
scoop.terminal / scoop.terminal.asyncio终端控制（以 crossterm 为基线移植）：ANSI 样式、光标、原始模式、输入协议解析、异步按键与尺寸事件。
scoop.readline交互式行编辑（移植自 rustyline）：历史、Emacs/Vi 模式、多行输入与补全。

更多示例

可以先用离线示例索引查找完整程序和运行说明：

$ scoop example --list
$ scoop example --search "异步"
$ scoop example async/tasks

库源码目录中的示例也可以直接运行：

$ cd ~/.scoop/src/scoop.asyncio/examples
$ scoop run --release tcp_echo.scoop

网络示例只使用本机回环地址；TLS 示例会现场生成短期证书。
