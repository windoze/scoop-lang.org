类、接口与对象

class、interface、object 与 companion object 是引用类型，语法与 Kotlin 基本一致。主要差异：类与成员默认 final，默认可见性是 internal，构造期间对 this 的使用受到严格限制，没有 data class 与 lateinit。

class

class Account(val owner: String, initial: Long) {
    var balance: Long = initial
    private val history = ArrayList<Long>()

    fun deposit(amount: Long) {
        if (amount <= 0L) throw IllegalArgumentException(Some("amount must be positive"))
        balance += amount
        history.add(amount)
    }

    val transactions: Long get() = history.size
}

fun main() {
    val account = Account("Ada", 100L)
    account.deposit(50L)
    println(f"${account.owner} ${account.balance} ${account.transactions}")
}
  • 类可以继承一个类、实现任意多个接口；类默认 final，需要 open、abstract 或 sealed 才能被继承。
  • 类的对象具有 identity，=== 比较是否同一对象。类不会自动获得 ==、toString 或哈希，需要时显式声明，见运算符与相等。
  • 没有 data class：需要结构相等、副本更新与解构的数据请使用 struct。

构造函数

主构造函数

类名后的参数列表声明主构造函数。参数写 val/var 时同时声明属性；不写时是普通构造参数，只在基类构造实参、属性初始值与 init 块中可见，不能在成员函数中使用。

class Point(val x: Int, val y: Int, label: String) {
    val description = f"${label} at ${x},${y}"     // 普通参数只能在初始化中使用
}

fun main() {
    println(Point(1, 2, "p").description)
}
  • 既没有写主构造函数也没有次构造函数的类，有一个隐式的零参数构造函数。
  • 构造函数默认是 internal，与其他声明一样。public 类要对其他 Cone 提供构造入口，必须写 public constructor：public class User public constructor(val name: String)。给主构造函数加修饰符或注解时都需要显式的 constructor 关键字。
  • 主构造参数与次构造函数都支持默认参数、命名参数和 vararg；vararg val xs: T 声明的属性类型是 Array<T>。

次构造函数

次构造函数写作 constructor(参数) : this(实参) { 函数体 } 或 : super(实参)。次构造函数的参数不能写 val/var。

  • 有主构造函数时，每个次构造函数都必须经 this(…) 直接或间接委托到主构造函数。
  • 没有主构造函数时，每条委托链都终止于一次 super(…)；省略委托等价于 super()。
  • 委托链不能成环。主构造函数与所有次构造函数共同组成一组重载。

初始化顺序

构造一个对象时依次执行：

  1. 调用方求值构造实参；
  2. 分配对象，所有字段从零值开始；
  3. 执行基类的完整构造（递归地遵守同样的顺序）；
  4. 写入带 val/var 的主构造参数；求值接口委托表达式；
  5. 按源码顺序交替执行属性初始值和 init 块；
  6. 由内向外执行次构造函数的函数体。
fun trace(tag: String): String {
    println(tag)
    return tag
}

open class Base(name: String) {
    val baseLabel = trace("base property")
    init { trace("base init") }
}

class Derived(name: String) : Base(trace("base argument")) {
    val first = trace("first property")
    init { trace("derived init") }
    val second = trace("second property")
    constructor() : this("anonymous") { trace("secondary body") }
}

fun main() {
    val d = Derived()
}

输出依次为 base argument、base property、base init、first property、derived init、second property、secondary body。任一步骤抛出异常时，后续步骤不执行，构造表达式不产生对象。

构造期间的 this

在构造函数、属性初始值和 init 块中，this 只能用于读写已经初始化的字段。它不能作为普通值传给函数、存储、返回或被 lambda 捕获，也不能用来调用成员方法（包括虚方法）。因此构造期间不会观察到尚未初始化的字段，基类构造也不会经虚调用进入派生类。

class Config {
    val a = 1
    fun doubled(): Int = a * 2
    val b = doubled()        // 编译错误：构造完成前不能通过 this 调用方法
    val c = d + 1            // 编译错误：d 尚未初始化
    val d = 2
}

需要复杂计算时，把逻辑放在顶层函数或 companion 中，以参数形式传入数据。构造期间也不能调用挂起函数；构造函数中可以执行 throw，但不能 return。

属性

形式含义
val p: T = expr / var p: T = expr存储属性，有 backing field，可以自定义访问器
val p: T get() = expr计算属性，没有存储
var p: T get() = … set(value) { … }可写的计算属性，必须同时提供 getter 和 setter
var p: T?（省略初值）初值为 None 的可选存储属性
val/var p: T by expr委托属性
abstract val/var p: T由子类实现的抽象属性
class Temperature {
    var celsius: Double = 0.0
        set(value) {
            if (value < -273.15) throw IllegalArgumentException(Some("below absolute zero"))
            field = value
        }

    val fahrenheit: Double get() = celsius * 9.0 / 5.0 + 32.0

    var note: String?                    // 省略初值：None

    var readings: Int = 0
        private set(value) { field = value }

    fun record(value: Double) {
        celsius = value
        readings++
    }
}

fun main() {
    val t = Temperature()
    t.record(100.0)
    println(f"${t.fahrenheit} ${t.readings} ${t.note == None}")
}
  • getter 没有参数；setter 恰有一个参数（通常命名为 value）并返回 Unit。val 不能有 setter。
  • field 只在存储属性访问器的函数体内表示 backing field。
  • setter 可以声明比属性更窄的可见性，例如 private set(value) { field = value }；目前必须写出 setter 的函数体。
  • Scoop 不支持 lateinit。唯一可以省略初值的存储属性是 var p: T?，其初值为 None；val p: T? 与 var p: T 仍须提供初值。
  • 属性可以从初值或 getter 推断类型；没有类型来源（例如块体 getter、抽象属性）时必须写类型。
  • 访问器总是同步、非挂起的；需要异步取得的值应暴露为 suspend fun。

常量

const val 声明编译期常量，只能出现在顶层、object 或 companion 中，必须写出类型和初值。初值必须是常量表达式：字面量、其他 const val、内建运算符与数值转换的组合。常量的类型可以是基本类型、String、Unit，或字段全部为常量的 struct、tuple 与 enum 值。普通函数调用、构造调用和 f-string 不是常量表达式。

const val MAX_RETRIES: Int = 3
const val TIMEOUT_MS: Long = MAX_RETRIES.toLong() * 1000L
const val GREETING: String = "hello"

object Limits {
    const val PAGE: Int = 50
}

fun main() {
    println(f"${TIMEOUT_MS} ${GREETING} ${Limits.PAGE}")
}

读取 object 中的 const val 不会触发该 object 的初始化。

顶层属性

顶层 val/var 可以保存任意类型的值。需要运行期计算的顶层属性在进入 main 之前同步初始化一次；同一 Cone 内的初始化顺序是确定的，但不按文件书写顺序，因此初始值不应依赖其他文件中顶层属性的副作用顺序。初始化表达式之间直接形成的依赖环是编译错误。一组相关的全局状态建议放在 object 中。

继承与覆写

abstract class Animal(val name: String) {
    abstract fun sound(): String
    open fun describe(): String = f"${name} says ${sound()}"
}

open class Dog(name: String) : Animal(name) {
    override fun sound(): String = "woof"
}

class Puppy(name: String) : Dog(name) {
    final override fun describe(): String = super.describe() + " (puppy)"
}

fun main() {
    val pets: Array<Animal> = [Dog("Rex"), Puppy("Bit")]
    for (p in pets) println(p.describe())
}
  • 派生类在类头写出基类与构造实参 : Base(args)；没有主构造函数的类只写基类类型，由次构造函数调用 super(args)。
  • 方法与属性默认 final；首次允许覆写需要 open。abstract 成员隐含 open，只能出现在抽象类或接口中。
  • 覆写必须写 override；override 成员默认仍可被进一步覆写，final override 终止覆写。
  • 属性覆写要求名称和类型完全相同；var 可以覆写 val，反之不行。
  • super.member(…) 直接调用直接基类中的实现，不经过虚分派；super 不是独立的表达式。
  • 抽象类不能直接构造；具体类必须实现继承来的全部抽象成员。
  • 泛型方法不能是 open、abstract 或 override，见泛型方法。

接口

接口可以声明抽象方法、带默认实现的方法和属性，不能有字段、初值、构造函数或 init 块。接口声明需要 body，空接口写作 interface Marker {}。

interface Named {
    val name: String
    fun greet(): String = f"hi, ${greetingName()}"
    private fun greetingName(): String = name     // private 辅助方法必须有函数体
}

interface Loud {
    fun greet(): String = "HEY"
}

class Person(override val name: String) : Named, Loud {
    override fun greet(): String = super<Named>.greet() + " / " + super<Loud>.greet()
}

fun main() {
    println(Person("Ada").greet())
}
  • 类继承的方法优先于接口默认实现；多个互不相关的默认实现冲突时，必须显式覆写，可以用 super<I>.member 调用某个直接父接口的默认实现。
  • 接口方法不能声明自己的类型参数，见泛型方法。
  • 接口成员同样默认 internal。public 接口的抽象成员必须显式写 public，实现它的成员要写 public override。
  • struct 与 enum 也可以实现接口，但不能实现要求 setter 的 var 属性。

object 与 companion

object O { … } 同时声明一个类型和它唯一的实例。object 可以继承一个类、实现接口，但不能有构造函数，O() 是编译错误。

object Registry {
    init { println("registry initialized") }
    val names = ArrayList<String>()
    fun register(name: String) {
        names.add(name)
    }
}

class User private constructor(val name: String) {
    companion object Factory {
        fun create(name: String): User = User(name)
    }
}

fun main() {
    println("start")
    Registry.register("scoop")         // 首次访问时初始化
    println(Registry.names.size)
    println(User.create("Ada").name)
    println(User.Factory.create("Lin").name)
}
  • object 与 companion 在首次访问时线程安全地初始化一次。初始化失败时异常会被记住，之后的访问都抛出同一异常，不会重试；初始化中形成的循环依赖抛出 IllegalStateException。
  • class、struct、enum、interface 与 object 各自至多有一个 companion object，省略名称时名为 Companion。companion 的成员可以用类型名直接访问：User.create(…)。
  • companion 不会被派生类继承，也不出现在实例的成员查找中。
  • 泛型类型的每个完整类型实参都有独立的 companion：Box<Int>.Companion 与 Box<String>.Companion 是不同的对象，各有自己的状态。引用泛型类型的 companion 时必须写出完整的类型实参，例如 Box<Int>.create(1)；companion 中可以使用宿主的类型参数。
class Box<T>(val value: T) {
    companion object {
        var created: Int = 0
        fun make(value: T): Box<T> = Box(value)
    }
}

fun main() {
    Box<Int>.created = 3
    val b = Box<String>.make("x")
    println(f"${Box<Int>.created} ${Box<String>.created} ${b.value}")   // 3 0 x
}

嵌套、inner 与局部类型

  • 嵌套类型：类型 body 中声明的 class、struct、enum、interface、object 是静态嵌套的，不能访问外层实例或外层的类型参数，通过 Outer.Nested 引用。
  • inner class：只能直接声明在 class 中，持有外层实例的引用，可以使用外层的成员和类型参数。创建时需要外层实例：outer.Inner(…)，在外层的成员中可以省略 outer；this@Outer 指外层实例。
  • 局部类型：代码块中可以声明 class、struct、enum 和 interface，它们在声明之后的块内可见，不能带可见性修饰符。局部 class 可以捕获外层的不可变绑定（遵守捕获规则）。
  • 匿名对象：object : Base(args), I { … } 是表达式，每次求值创建一个新的匿名 final 类实例。
interface Shape {
    fun area(): Double
}

class Outer(val tag: String) {
    inner class Inner(val n: Int) {
        fun show(): String = f"${tag}-${n}"      // 访问外层实例的属性
    }
    class Nested {
        fun show(): String = "nested"
    }
}

fun main() {
    val outer = Outer("o")
    println(outer.Inner(1).show())
    println(Outer.Nested().show())

    val side = 3.0
    val square = object : Shape {
        override fun area(): Double = side * side
    }
    class Circle(val r: Double) : Shape {
        override fun area(): Double = 3.14159 * r * r
    }
    println(square.area() + Circle(1.0).area())
}

局部变量可以保留匿名对象的类型并访问它自己的成员；非局部函数或属性不能推断出匿名类型或局部类型作为签名，需要显式标注为可见的父类型。

sealed 类型

sealed class 与 sealed interface 限制直接子类型：直接子类型必须与 sealed 声明位于同一个 Cone 的同一个 package，并且是具名的非局部声明（可以是 class、object、struct 或 enum）。when 根据这个封闭的集合检查穷尽性，见穷尽性。

sealed class Result {
    class Success(val value: Int) : Result()
    class Failure(val message: String) : Result()
    object Pending : Result()
}

fun render(r: Result): String = when (r) {
    is Result.Success -> f"ok ${r.value}"
    is Result.Failure -> f"error ${r.message}"
    is Result.Pending -> "pending"
}

fun main() {
    println(render(Result.Success(1)))
    println(render(Result.Pending))
}
  • sealed class 隐含 abstract，不能直接构造；其构造函数只能是 protected（默认）或 private。
  • 子类型本身可以是 open 或继续 sealed；非 sealed 的子类型代表一个开放的家族，is Child 覆盖整个家族。
  • 匿名 object 不能成为 sealed 类型的直接子类型。

可见性

修饰符顶层声明成员
public任何依赖该 Cone 的代码能看到所属类型的任何代码
internal（默认）同一个 Cone同一个 Cone
protected不适用声明它的类及其子类的 body（仅 class 成员）
private同一个源文件声明它的类型内部
  • 省略修饰符就是 internal，可见性不会从外层类型、基类或接口继承。对外公开的 API 必须显式写 public。
  • 成员的实际可见范围是它自身的可见性与所有外层类型可见性的交集。
  • 覆写省略修饰符时同样是 internal：覆写 public 接口或基类的成员必须写 public override，否则是编译错误。
  • 通过显式接收者访问 protected 成员时，接收者的静态类型必须是当前类或其子类。
  • private 成员不会被继承或覆写；internal open 成员只能在同一 Cone 中覆写。
  • 公开声明的签名（参数、结果、父类型、上界）不能引用可见范围更小的类型。

委托

属性委托

val/var p: T by expr 把属性的读写交给委托对象。委托对象通过显式声明为 operator 的成员或扩展提供以下函数：

  • operator fun getValue(thisRef: R): T（必需）；
  • operator fun setValue(thisRef: R, value: T): Unit（var 必需）；
  • operator fun provideDelegate(): D（可选，在初始化时调用一次，返回真正的委托）。

R 是成员属性的所属类型、扩展属性的接收者类型，局部与顶层属性则为 Unit。协议中没有属性名或反射信息，需要时在 by 表达式中显式传入。

class Lazy<T>(val compute: () -> T) {
    var cached: T? = None
    operator fun getValue(thisRef: Unit): T = when (val c = cached) {
        case Some(v) -> v
        case None -> {
            val v = compute()
            cached = Some(v)
            v
        }
    }
}

class Observable(var current: Int) {
    operator fun getValue(thisRef: Model): Int = current
    operator fun setValue(thisRef: Model, value: Int) {
        println(f"changed to ${value}")
        current = value
    }
}

class Model {
    var score: Int by Observable(0)
}

fun main() {
    val answer by Lazy { println("computing"); 42 }
    println(answer)        // computing, 42
    println(answer)        // 42
    val m = Model()
    m.score = 5            // changed to 5
}

委托表达式在属性初始化时求值一次。委托调用是同步的，可以分配内存和抛出异常，但不能挂起。struct 与 enum 不能有委托属性。

接口委托

class 或 object 的接口列表中可以写 I by expr：未被显式实现的接口成员自动转发给 expr 的值。表达式在构造时求值一次并保存在实例中。

interface Printer {
    fun print(text: String): String
    fun name(): String = "printer"
}

class Exclaim : Printer {
    override fun print(text: String): String = text + "!"
}

class Logged(inner: Printer) : Printer by inner {
    override fun name(): String = "logged"      // 显式实现优先于转发
}

fun main() {
    val p = Logged(Exclaim())
    println(p.print("hi") + " " + p.name())
}

转发优先于接口的默认实现；多个委托都能提供同一个成员时必须显式覆写。被委托对象内部的调用仍作用于它自身，不会转到宿主的覆写。

条件接口实现

泛型类型可以只在类型实参满足条件时实现某个接口。在类型 body 中写 override interface 接口 where 条件 { 成员 }：

struct Box<T>(val value: T) {
    override interface ToString where T : ToString {
        public override fun toString(): String = f"Box(${value.toString()})"
    }
    override interface Hash where T : Hash {
        public override fun hash(): Long = value.hash()
    }
}

fun main() {
    println(Box("x"))                      // Box<String> 实现了 ToString
    println(Box(3).hash() == 3.hash())     // Box<Int> 实现了 Hash
}
  • 条件只影响该接口是否成立：Box<T> 对任意 T 都可以构造和使用，只有 T : ToString 时 Box<T> 才是 ToString。
  • where 子句必填，条件可以是宿主类型参数的类或接口上界、value/ref，或 T.Companion : I。
  • 块中只能包含实现目标接口的覆写成员，不能有字段、构造函数、嵌套声明或辅助函数。块只能写在类型自己的 body 中，不能在别处为已有类型追加实现。
  • 同一类型对同一接口的多份实现不能有可能重叠的适用范围。

release 块

直接持有原生资源的 final class 可以声明一个 release { … } 块，在对象被垃圾回收时尽力清理遗漏释放的资源：

@Extern(name = "malloc")
fun nativeAlloc(size: ULong): Option<Ptr<Unit>>

@Extern(name = "free")
fun nativeFree(address: Ptr<Unit>)

final class NativeBuffer private constructor(private var handle: Option<Ptr<Unit>>) : Closeable {
    public override fun close() {
        val owned = handle
        handle = None                       // 先置为惰性状态，再释放
        when (owned) {
            case Some(p) -> @Unsafe { nativeFree(p) }
            case None -> {}
        }
    }

    release {
        when (handle) {
            case Some(p) -> @Unsafe { nativeFree(p) }
            case None -> {}
        }
    }

    companion object {
        @Unsafe
        fun allocate(size: ULong): NativeBuffer = NativeBuffer(nativeAlloc(size))
    }
}

fun main() {
    @Unsafe {
        NativeBuffer.allocate(64uL).use { println("using buffer") }
    }
}
  • 宿主必须是普通的、可实例化的 final class，不能是 open/abstract/sealed、object、struct 或异常类。
  • 块内只能读取本类自己声明的字段的副本，不能使用 this、调用本对象的方法或写字段。
  • 块内的操作必须不分配托管对象、不抛异常、不挂起，读取的值必须是不含托管引用的类型（数值、Ptr 等）；可以在 @Unsafe 中直接调用 C 函数，或调用满足同样限制的 @NoGC 辅助函数。
  • 它不保证何时执行、在哪个线程执行，也不保证程序退出时执行；只有构造成功的对象才会执行。确定性释放仍然依靠 close 与 use，release 只是兜底。

Scoop 没有终结器、析构函数或对象复活。
