表达式与控制流

本章介绍函数体中的语句、运算符与控制结构。Scoop 的控制流语法沿用 Kotlin：if、when 与 try 都是表达式，return、break、continue 和 throw 可以出现在表达式位置。when 的模式匹配见 when 与模式匹配。

语句

代码块 { … } 由一系列语句组成，每个块建立自己的词法作用域。语句可以是：

  • 局部声明：val/var 变量（可以使用解构）、局部函数、局部 class/struct/enum/interface、typealias，以及块级 import；
  • 赋值：x = e、复合赋值 x += e、自增自减 x++；赋值本身不是表达式，不能出现在其他表达式内部；
  • 表达式语句：函数或方法调用（包括安全调用），以及 if、when、try、循环、return、break、continue、throw。其他表达式单独成为语句是编译错误，例如一行只写 a + b、x!! 或构造调用 Point(1, 2)；只需要副作用时，可以把结果绑定给 val _ = …。
fun main() {
    val limit = 3                 // 不可重新赋值
    var count = 0                 // 可变
    count += limit
    count++
    val x = 1
    if (count > 0) {
        val x = 2                 // 内层块可以遮蔽外层名称
        println(x)
    }
    println(f"${count} ${x}")
}
  • 局部变量必须在声明处初始化；类型可以省略，由初值推断。
  • 同一个作用域内不能重复声明同名变量；内层块可以声明与外层同名的变量来遮蔽它。
  • val 只表示绑定不可重新赋值，不表示所引用的对象不可变。
  • 局部函数与局部类型在声明之后可见（局部函数在自身体内也可见，可以直接递归），不能前向引用。

运算符优先级

下表从高到低列出运算符的优先级，同一行的运算符优先级相同。二元运算符都是左结合，Elvis ?: 是右结合。

因为位运算是中缀函数，它们的优先级低于算术和区间、高于比较：flags and mask == 0 等于 (flags and mask) == 0，a and b + 1 等于 a and (b + 1)。中缀函数之间没有自定义优先级，一律左结合。

运算符概览

  • 算术 + - * / % 与比较 < <= > >= 对数值类型是内建的，对其他类型通过 operator 函数重载。数值运算要求两侧类型相同，见整数与浮点数。
  • 相等 ==/!= 调用左侧静态类型上的 operator fun equals；===/!== 比较引用 identity，只能用于引用类型。见相等。
  • 逻辑 &&、|| 只接受 Boolean，短路求值；! 取反。它们不能重载。
  • 包含 a in b 调用 b.contains(a)，!in 对结果取反。
  • 字符串拼接 s + t 要求两侧都是 String；拼接其他值请用 f-string。
  • 空安全 ?.、?:、!! 见 Option 与空安全；类型运算 is、as、as? 见类型检查与转换。

if 表达式

if 既可以作为语句，也可以作为表达式。作为值使用时必须有 else 分支；分支是代码块时，块中最后一个表达式的值就是分支的值。分支也可以是单个语句或表达式，不必写花括号。else if 就是 else 分支中嵌套的 if。

fun sign(x: Int): Int {
    if (x < 0) return -1 else if (x > 0) return 1
    return 0
}

fun classify(x: Int): String {
    val size = if (x > 100) {
        val excess = x - 100
        f"large (+${excess})"
    } else "small"
    return size
}

fun main() {
    println(sign(-5))
    println(classify(150))
}

值位置的 if 缺少 else 是编译错误。各分支结果的类型按分支合并规则确定；以 return、throw 等结束的分支不参与合并。空块或以声明、赋值结尾的块的值是 Unit。

when 表达式

when 依次检查各分支条件，执行第一个成立的分支。不带 subject 时每个条件都是 Boolean 表达式，可以替代 if-else if 链：

fun grade(score: Int): String = when {
    score >= 90 -> "A"
    score >= 75 -> "B"
    else -> "C"
}

fun main() {
    println(grade(80))
}

带 subject 的 when、类型分支、in 分支、case 模式和穷尽性规则见 when 与模式匹配。

try 表达式

try 也是表达式：结果是正常完成的 try 块或所执行的 catch 块的最后一个表达式；finally 块的值总是被丢弃。

fun parse(text: String): Int = try {
    if (text == "bad") throw IllegalArgumentException(Some("bad input"))
    text.charLength.toInt()
} catch (e: IllegalArgumentException) {
    -1
} finally {
    println("parsed")
}

fun main() {
    println(parse("bad"))
    println(parse("good"))
}

异常的匹配规则与 finally 的执行时机见异常与资源。

循环

while 与 do-while

while (条件) 循环体 在每轮开始前求值条件。do 循环体 while (条件) 先执行循环体，再求值条件；循环体最外层声明的名称在条件中可见，在循环之后不可见。

fun main() {
    var i = 0
    while (i < 3) i++

    var total = 0
    do {
        val next = total + i
        total = next
    } while (next < 10)
    println(f"${i} ${total}")
}

for

for (模式 in 源) 循环体 遍历任何提供 operator fun iterator() 的值，包括数组、列表、字符串、区间和各种集合。执行过程：

  1. 源表达式求值一次，再调用一次 iterator()；返回值必须实现唯一一个 Iterator<T>；
  2. 每轮调用一次 next()：返回 Some(v) 时把 v 绑定到循环变量并执行循环体，返回 None 时结束循环。

每一轮的循环变量都是新的只读绑定，闭包捕获的是该轮的值。循环变量位置可以写不可失败的解构模式，但不能写 Some(x) 这类可能失败的模式。

fun main() {
    for (word in ["alpha", "beta"]) println(word)
    for (c in "雪😀") print(c)
    println("")
    for ((name, score) in [("Ada", 90), ("Lin", 85)]) println(f"${name}: ${score}")
}

区间

整数类型提供以下构造区间的成员。结果是 IntRange、LongRange、UIntRange 或 ULongRange：Int8/Int16/Int 得到 IntRange（元素为 Int），UInt8/UInt16/UInt 得到 UIntRange，Long、ULong 各自得到同名区间。

写法含义
a..b从 a 升序到 b，包含 b；a > b 时为空
a..<b、a until b从 a 升序，不包含 b；a >= b 时为空
a downTo b从 a 降序到 b，包含 b；a < b 时为空
r step n保持方向与端点，把步长改为 n；n 必须为正，否则抛出 IllegalArgumentException
x in rx 位于端点范围内且与起点按步长对齐
fun main() {
    for (i in 10 downTo 1 step 3) print(f"${i} ")      // 10 7 4 1
    println("")
    for (i in 0 until 10 step 4) print(f"${i} ")       // 0 4 8
    println("")
    println(4 in (0..10 step 2))                        // true
    for (i in Int.MAX_VALUE - 1..Int.MAX_VALUE) print(f"${i} ")   // 端点为 MAX_VALUE 也能正确结束
    println("")
}

区间是不可变对象，每次 iterator() 都从起点开始。迭代在越过端点或即将溢出前停止，因此 MIN_VALUE/MAX_VALUE 端点是安全的。没有 Char 区间或浮点区间。

跳转

break 与 continue

break 退出最内层循环，continue 进入它的下一轮：while 与 do-while 重新求值条件，for 调用下一次 next()。用 label@ 给循环加标签后，break@label 与 continue@label 作用于该循环：

fun main() {
    outer@ for (i in 0..3) {
        for (j in 0..3) {
            if (j == 2) continue@outer
            if (i == 2) break@outer
            print(f"${i}${j} ")
        }
    }
    println("")      // 00 01 10 11
}

标签只能用于循环和 lambda 等函数值，不提供 goto，也不能跳出普通块。break/continue 不能越过函数边界：lambda、匿名函数和局部函数中不能跳出外层函数的循环。

return

return 表达式 从当前具名函数或匿名函数返回；返回 Unit 的函数可以写裸 return。表达式体函数（fun f() = …）中不能使用 return。lambda 中的裸 return 是编译错误，要从 lambda 局部返回请使用 return@label，标签默认是接收该 lambda 的函数名，见 lambda 的返回。

跳转表达式

return、break、continue 与 throw 在表达式位置的类型是 Nothing，可以出现在 Elvis 右侧、分支或实参中：

fun firstPositive(values: Array<Int>): Int? {
    for (v in values) {
        val positive = if (v > 0) v else continue
        return Some(positive)
    }
    return None
}

fun main() {
    println(firstPositive([-1, 0, 3, 5]) ?: 0)
}

跳转发生时，后续的实参、默认参数和外层调用都不会执行；沿途的 finally 块按从内到外的顺序执行。

求值顺序

Scoop 严格从左到右求值，并保证每个子表达式只求值一次：

  • 二元运算先求值左操作数，再求值右操作数。唯一的例外是 a in b 与 a !in b：它们等价于 b.contains(a)，先求值 b（与 Kotlin 相同）。
  • 调用先求值接收者，再按实参在源码中出现的顺序求值，不受命名实参映射到哪个形参的影响；所有显式实参都先于默认参数求值，见实参的求值。
  • 复合赋值与自增自减中，接收者与下标只求值一次：a[i()] += v() 依次求值 a、i()、v()。
  • &&、||、?:、?. 的右侧只在需要时求值。
fun log(tag: String, value: Int): Int {
    print(tag)
    return value
}

fun diff(x: Int, y: Int): Int = x - y

fun main() {
    val inside = log("a", 1) in log("b", 0)..log("c", 5)   // 输出 bca
    println("")
    println(diff(y = log("y", 1), x = log("x", 3)))       // 输出 yx2
}
