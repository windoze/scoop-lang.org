函数与闭包

函数语法整体与 Kotlin 一致：默认参数、命名参数、vararg、扩展函数、lambda 与尾随 lambda 都按熟悉的方式工作。最重要的差异是闭包按值捕获、不能捕获 var，以及函数值不保留参数名和默认值。

函数声明

fun add(a: Int, b: Int): Int {
    return a + b
}

fun square(x: Int) = x * x          // 表达式体，结果类型推断为 Int

fun log(message: String) {          // 块体省略结果类型：返回 Unit
    println(message)
}

fun main() {
    log(f"${add(1, 2)} ${square(4)}")
}
  • 函数可以声明在顶层、类型内部（成员函数）、其他函数内部（局部函数），或以扩展函数的形式声明。
  • 表达式体 = expr 省略结果类型时从表达式推断；表达式体中不能使用 return。块体省略结果类型时结果为 Unit。
  • 结果不是 Unit 的函数，每条能正常结束的路径都必须返回值（或抛出异常）；无法确定时是编译错误。
  • 结果类型为 Nothing 的函数不能正常结束，只能抛出异常、调用另一个 Nothing 函数或永不结束。
  • 递归函数的结果类型推断不能依赖自身，此时需要显式写出结果类型。推断出的签名同样受可见性约束，不能暴露私有或局部类型。
  • 函数签名只由参数类型组成：参数名、默认值、结果类型与 suspend 都不能单独区分重载。

参数

参数可以是必需参数、带默认值的参数或 vararg 参数。参数在函数体内不可重新赋值。

默认参数

fun greet(name: String, greeting: String = "Hello", punctuation: String = "!"): String =
    f"${greeting}, ${name}${punctuation}"

fun window(start: Int, end: Int = start + 10): Int = end - start

fun main() {
    println(greet("Ada"))
    println(greet("Ada", punctuation = "?"))
    println(window(5))
}
  • 默认值表达式可以引用此前的参数，不能引用自身或之后的参数。
  • 默认值在定义处完成名称解析与类型检查，但在每次省略该参数的调用中重新求值，不会缓存。调用方的 import 或同名声明不会改变默认值的含义。
  • 默认值中引用的声明必须在函数所有合法的调用位置可见：public 函数的默认值不能引用 private 或 internal 的实现细节。
  • 抽象函数和接口方法可以声明默认值；override 不能重新声明默认值，而是继承被覆写声明的默认值。

命名实参

实参可以按位置传递，也可以写成 name = value。在跳过某个位置或改变顺序的命名实参之后，括号内的其余实参都必须命名。不能通过只写后面的位置实参来跳过中间有默认值的参数。

fun connect(host: String, port: Int = 80, secure: Boolean = false): String =
    f"${host}:${port} secure=${secure}"

fun main() {
    println(connect("a.example", secure = true))         // 跳过 port
    println(connect(port = 8443, host = "b.example"))    // 任意顺序
    println(connect(host = "c.example", 9000))           // 命名实参位于自己的位置时，之后仍可按位置传递
}

覆写方法的参数名不参与匹配；命名调用使用调用点静态类型上那个声明的参数名。

vararg

一个参数列表至多有一个 vararg 参数。vararg xs: T 中的 T 是元素类型，函数体内 xs 的类型是 Array<T>：

fun sum(vararg values: Int): Int {
    var total = 0
    for (v in values) total += v
    return total
}

fun join(prefix: String, vararg parts: String, separator: String = ","): String {
    var result = prefix
    for (p in parts) result = result + separator + p
    return result
}

fun main() {
    val more = [4, 5]
    println(sum())                    // 0：没有元素时得到新的空数组
    println(sum(1, 2, 3))
    println(sum(1, *more, 6))         // 展开 *array，可与普通元素混合
    println(sum(values = more))       // 命名形式直接传入整个数组
    println(join("p", "a", "b", separator = ";"))
}
  • 位置实参到达 vararg 位置后，之后的未命名实参都属于它；其后的参数只能用命名实参或尾随 lambda 提供。
  • 展开 *expr 要求类型正好是 Array<T>：Array<String> 不能展开给 vararg xs: Any。
  • 未命名的元素（包括展开）总是复制进一个新数组，即使只有一个 *array；命名形式 xs = array 直接使用该数组。
  • vararg x: T 与普通参数 x: Array<T> 的签名相同，不能据此重载。

尾随 lambda

最后一个参数是函数类型时，lambda 可以写在圆括号之后；括号内没有其他实参时可以省略括号。尾随 lambda 总是对应最后一个参数，最后一个参数不能是 vararg。

fun repeat(times: Int, action: (Int) -> Unit) {
    for (i in 0 until times) action(i)
}

fun measure(block: () -> Int): Int = block()

fun main() {
    repeat(3) { i -> print(i) }
    println("")
    println(measure { 40 + 2 })
}

factory() { … } 把 lambda 交给 factory；(factory()) { … } 则调用 factory 返回的值。每次调用最多有一个圆括号外的 lambda。

实参的求值

一次调用严格按以下顺序执行：

  1. 求值接收者（如果有），只求值一次；
  2. 按实参在源码中出现的顺序求值所有显式实参，不受命名映射的影响；尾随 lambda 位于最后；
  3. 按参数声明顺序组装完整的参数：构造 vararg 数组，并对省略的参数求值默认值；
  4. 进入函数体。

因此所有显式实参都先于任何默认值求值。例如 f(y = n(), x = m()) 先执行 n() 再执行 m()。

扩展函数与扩展属性

扩展函数为已有类型添加可以用成员语法调用的函数，函数体内用 this 访问接收者：

fun String.shout(): String = this + "!"

fun <T> Array<T>.second(): T = this[1]

val String.initial: Char get() = this.getCharAt(0L)

fun main() {
    println("hey".shout())
    println(["a", "b"].second())
    println("Scoop".initial)
}
  • 扩展是静态解析的：按接收者的静态类型选择，不做运行期分派。
  • 同名成员优先于扩展：类型自身有适用的成员时，扩展不会被选中。
  • 扩展不能访问接收者的 private 或 protected 成员。
  • 扩展属性只能声明在顶层，没有 backing field，只能是计算属性或委托属性。泛型扩展属性的类型参数必须能由接收者类型唯一确定。
  • 扩展可以像普通函数一样被导入、重载和引用（String::shout）。

局部函数

函数体内可以声明具名的局部函数。局部函数在其自身体内及声明之后可见，因此可以直接递归，但不能前向调用之后声明的局部函数。局部函数与 lambda 一样遵守捕获规则。

fun main() {
    val base = 10L
    fun factorial(n: Long): Long = if (n <= 1L) 1L else n * factorial(n - 1L)
    fun scaled(n: Long): Long = factorial(n) * base
    println(scaled(5L))
}

函数类型

函数类型写作 (P1, P2) -> R，无参数时写作 () -> R。挂起函数类型写作 suspend (P) -> R；带接收者的函数类型写作 A.(P) -> R 或 suspend A.(P) -> R。

  • 函数类型是引用类型。函数值可以携带捕获的环境，由 GC 管理。
  • 函数类型的身份由是否挂起、接收者、各参数类型与结果类型决定，不包含参数名、默认值或 vararg。
  • 参数类型逆变、结果类型协变：(Any) -> String 可以用作 (String) -> Any。普通函数类型与挂起函数类型之间没有转换。
  • 带接收者的函数类型与“把接收者作为第一个参数”的普通函数类型可以相互适配：Int.() -> Int 的值可以赋给 (Int) -> Int，反之亦然。
  • 函数值用 f(args) 或 f.invoke(args) 调用，带接收者的还可以写 receiver.f(args)。调用函数值时只能按位置传入与类型元数相同的实参：不支持命名实参和默认值，最后一个位置可以用尾随 lambda。
  • 函数值没有结构相等；=== 可以比较同一个已保存的函数值，但对同一函数多次创建的引用或 lambda 不保证相同。
fun main() {
    val general: (Any) -> String = { value -> "seen" }
    val specific: (String) -> Any = general            // 参数逆变、结果协变
    val square: Int.() -> Int = { this * this }
    val flat: (Int) -> Int = square                    // 接收者与首参数互相适配
    println(f"${specific("x") is String} ${3.square()} ${flat(4)}")
}

lambda 与匿名函数

lambda 写作 { 参数 -> 函数体 }，函数体中最后一个表达式的值就是结果。匿名函数写作 fun(参数): R { 函数体 }，使用普通函数的 return 规则。在它们前面加 suspend 得到挂起版本。

fun apply(x: Int, f: (Int) -> Int): Int = f(x)

fun main() {
    val add = { a: Int, b: Int -> a + b }          // 无期望类型时需要标注参数类型
    println(apply(5) { it * 2 })                     // 单参数可以省略参数列表，使用 it
    println(apply(5, { x -> x + add(1, 2) }))
    val clamp = fun(x: Int): Int {
        if (x < 0) return 0
        return x
    }
    println(clamp(-3))
    val describe = fun String.(times: Int): String { return this + "×" + times.toString() }
    println("a".describe(3))
}
  • 有期望的函数类型时，参数类型可以省略；没有期望类型时，每个参数都必须标注类型。
  • 期望类型的参数个数为 1 且省略了参数列表时，隐式参数名为 it。无参数的 lambda 写作 { 函数体 }。
  • 参数可以使用不可失败的解构模式：{ (key, value) -> … }。一个模式仍然只对应一个参数。
  • 期望结果类型为 Unit 时，最后一个表达式的值被丢弃。
  • 期望类型是带接收者的函数类型时，lambda 中的 this 指向该接收者。
  • 普通 lambda 不会因为期望类型是挂起函数类型而自动变成挂起 lambda，必须显式写 suspend { … }。

lambda 的返回

lambda 中的裸 return 是编译错误：Scoop 没有非局部返回。从 lambda 局部返回使用 return@label。直接作为具名调用实参的 lambda 自动以被调函数名为标签；也可以用 label@ { … } 显式命名。

fun each(values: Array<Int>, action: (Int) -> Unit) {
    for (v in values) action(v)
}

fun main() {
    each([1, 2, 3]) {
        if (it == 2) return@each       // 只结束本次 lambda 调用
        print(it)
    }
    println("")
    each([1, 2, 3]) skip@{
        if (it == 1) return@skip
        print(it)
    }
    println("")
}

标签只能命中当前函数值，不能越过嵌套的 lambda 或函数返回到更外层；break/continue 同样不能跨越函数值边界。

捕获规则

lambda、匿名函数、局部函数和局部类只能捕获外层的 val、参数、接收者 this 等不可重新绑定的名称。读取或写入外层局部 var 都是编译错误。

  • 捕获在函数值创建时按值发生：值类型复制完整的值，引用类型复制引用。
  • 编译器不会把 var 隐式提升为共享单元，也不做 Java 式的 effectively-final 分析：需要捕获时先显式绑定为 val。
  • 多个闭包需要共享可变状态时，显式捕获一个引用对象，并修改它的属性。
  • 顶层属性和 object 的属性不是局部变量，可以直接读写；类的可变属性通过捕获的 this 访问。
class Counter {
    var count = 0
}

fun makeCounter(): () -> Int {
    val state = Counter()             // 捕获引用对象，而不是 var
    return {
        state.count += 1
        state.count
    }
}

fun main() {
    val next = makeCounter()
    next()
    next()
    println(next())                   // 3

    var total = 10
    val snapshot = total              // 需要当前值时先存入 val
    val addTotal = { x: Int -> x + snapshot }
    total = 20
    println(addTotal(1))              // 11
}
fun main() {
    var n = 0
    val read = { n + 1 }      // 编译错误：cannot capture mutable local `n`
}

函数引用

:: 创建指向已有声明的函数值。函数名出现在普通值位置时不会自动变成函数值，必须显式写 ::name。

写法结果
::name顶层函数或局部函数；跨 package 的函数先 import
::TypeName构造函数
Type::member未绑定的成员引用，接收者成为第一个参数
receiver::member绑定接收者的引用；接收者在创建时求值一次
::extension / receiver::extension未绑定或绑定的扩展函数引用
class Greeter(val name: String) {
    fun greet(): String = f"hi, ${name}"
}

fun twice(x: Int): Int = x * 2
fun <T> identity(x: T): T = x
fun String.shout(): String = this + "!"

fun main() {
    val f = ::twice                         // (Int) -> Int
    val make = ::Greeter                    // (String) -> Greeter
    val unbound = Greeter::greet            // (Greeter) -> String
    val bound = make("Ada")::greet          // () -> String
    val id: (String) -> String = ::identity // 泛型函数需要期望类型确定全部类型实参
    val loud = String::shout
    println(f"${f(4)} ${unbound(make("Lin"))} ${bound()} ${id("x")} ${loud("hey")}")
}
  • 有重载时，由期望函数类型选择目标；没有期望类型时，只有唯一能独立确定签名的候选才能被引用。
  • 引用虚成员或接口成员时，每次调用仍按接收者做动态分派。
  • 函数引用不保留参数名、默认值或 vararg 约定，调用时必须提供完整的参数列表。
  • 抽象类、接口和 object 没有可引用的构造函数。
  • 期望类型为 FunPtr<F> 时，::name 解析为原生回调地址而不是函数值，见原生互操作。

重载决议

同名函数可以按参数类型重载。调用时编译器按以下步骤选出唯一的目标：

  1. 分层收集候选：先查局部声明，再查隐式 this 的成员，然后是块级 import、文件的显式 import、当前 package、通配 import 和核心库 prelude，完整顺序见名称查找。显式接收者的调用先查成员，再按相同的作用域层查扩展。
  2. 逐层检查适用性：每个候选独立完成实参到形参的映射与泛型推断。只在第一个含有适用候选的层中选择；某一层只有同名但不适用的声明时，继续查找下一层。
  3. 选择最具体的候选：若一个候选的参数都能传给另一个候选而反之不行，它更具体。仍然并列时，非泛型候选优先，实际使用默认值更少的候选优先，没有 vararg 的候选优先。
  4. 仍不唯一则为歧义，是编译错误；诊断会列出相关候选与失败原因。
fun show(x: Any): String = "any"
fun show(x: String): String = "string"

fun size(x: Int, unit: String = "B"): String = "with default"
fun size(x: Int): String = "exact"

fun main() {
    println(show("s") + " " + show(1))     // string any
    println(size(1))                       // exact：使用的默认值更少
}
  • 结果类型不参与重载决议，只相差结果类型的两个函数是重复声明。
  • 整数字面量可以适配多个整数类型：f(1) 在 f(Int) 与 f(Long) 之间选择默认的 Int；若候选是 f(Long) 与 f(Int8)，两者都不是默认类型，调用有歧义。
  • lambda 实参由每个候选提供的期望类型检查，lambda 的结果类型不作为额外的优先规则。

挂起函数

suspend fun 声明协程挂起函数，只能在另一个挂起函数或挂起 lambda 中调用；main 必须是普通函数。挂起性是签名的一部分，覆写时必须一致。详见协程与并发。

task-local Context

Scoop 保留 Kotlin 的 context(name: T) 写法，但语义是属于当前逻辑任务的动态绑定，而不是在调用点隐式传参。声明处用 context(…) 前缀列出所需的类型，调用方用 context(value) { … } 在一段代码中安装绑定：

interface Logger {
    fun write(message: String)
}

class ConsoleLogger : Logger {
    override fun write(message: String) {
        println(message)
    }
}

context(logger: Logger)
fun report(message: String) {
    logger.write(f"[report] ${message}")
}

fun process() {
    report("processing")              // 中间函数不需要声明 context
}

fun main() {
    val logger: Logger = ConsoleLogger()
    context(logger) {
        process()
    }
}
  • 绑定按精确的静态类型查找，不考虑子类型：用 ConsoleLogger 类型的值安装的绑定不满足对 Logger 的需求。上例先把值赋给 Logger 类型的变量再安装。
  • 进入带 context(…) 的函数体时按顺序取得全部绑定；缺少任一绑定时抛出 MissingContextException，由调用方捕获。
  • 键必须是非空的引用类型（class、interface、String、数组、函数值等），值类型和 Option 不能直接作为键。同一列表中的键不能重复，同一类型的多种角色需要不同的包装类型。
  • context(value) { … } 一次安装一个绑定，多项用嵌套。内层同类型的绑定覆盖外层，离开代码块（包括 return、异常）时恢复；挂起不算离开。
  • 前缀可以用于顶层、成员、扩展和局部的具名函数，以及计算属性；不能用于构造函数、lambda、函数类型或 @Extern/@NoGC 声明。上下文列表不参与重载与函数类型。
  • startCoroutine、launch、async 启动的子任务继承启动时的绑定快照，之后父子任务各自的重新绑定互不影响。普通闭包不会捕获 Context。

兼容修饰符

inline、noinline、crossinline、reified 与 tailrec 为兼容 Kotlin 源码而被接受，但解析后完全忽略：它们不会内联、不做尾递归优化、不放宽 lambda 中的 return 或捕获限制。泛型本来就是单态化的，不需要 reified；是否内联由编译器自行决定。
