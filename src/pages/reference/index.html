参考文档

本参考完整描述 Scoop 语言的语法与语义，以及随工具链发布的核心库和标准库。它按主题组织，适合查阅某条规则的准确含义；想先快速上手，请阅读语言导览和用户指南。

文档结构

参考文档分为两部分。语言参考说明源码如何书写、类型如何检查、程序如何求值；标准库说明默认可用的核心库 scoop.core、各个库 Cone 的用途和测试库。每个类型与函数的完整签名请查阅由 scoop doc 生成的 API 文档。

阅读约定

  • 代码示例：本参考中的 Scoop 代码块都用配套工具链做过类型检查。标为“编译错误”的代码用来说明被拒绝的写法，注释指出出错的位置；需要 Cone.toml、多个文件或 native 库的片段只作说明。
  • 编译错误与运行期异常：“是编译错误”表示编译器拒绝该程序；“抛出 X”表示程序能编译，运行到该处时抛出异常 X。Scoop 不把可以静态判定的错误推迟到运行期。
  • 值类型与引用类型：值类型（struct、enum、tuple 及基本类型）没有 identity，复制时复制完整值；引用类型（class、interface、object、函数、数组、String 等）的值是指向堆对象的引用。很多规则依此区分，见类型系统。
  • Cone：Scoop 的模块、依赖与编译单位，相当于其他语言的 crate 或 module；internal 可见性即“同一 Cone 内可见”。见 Cone、package 与 import。
  • 命令名：本参考中的 scoop … 命令在 Windows 上写作 sco …，见快速开始。
  • 未提及即不支持：Scoop 以 Kotlin 核心语法为基础。本参考没有描述的 Kotlin 特性（例如 data class、lateinit、型变修饰符、运行期反射）在 Scoop 中不存在；差异汇总见对比 Kotlin。

程序的组成

一个 Scoop 程序由一个可执行 Cone 和它依赖的库 Cone 组成。最简单的程序是一个 .scoop 文件，scoop run 会把它当作只含这一个文件的可执行 Cone，并默认依赖核心库与标准库：

fun main() {
    val language = "Scoop"
    println(f"Hello, ${language}!")
}
$ scoop run --release hello.scoop
Hello, Scoop!

源文件由可选的 package 声明、若干 import 和顶层声明组成。顶层声明包括函数、属性、类型（class、interface、object、struct、enum）、typealias 与注解类。程序从唯一的 main 函数开始执行；进入 main 之前，所有需要运行期初始化的顶层属性已经按确定的顺序初始化完毕。入口签名、退出码与命令行参数见程序入口。

多文件项目使用带 Cone.toml 的 Cone 目录，用 scoop new 创建，详见Cone 清单与用户指南。

规范与版本

本参考依据 Scoop 仓库 docs/specs/ 中的语言、运行时与库规范，并以工具链 scoop 0.0.0-dev（revision ae13036d9）的实际行为校对；Windows 目标相关的内容依据 revision b0de03700 的规范与 Windows 实施记录。规范面向实现者，包含 ABI、产物格式与编译器内部契约等细节；本参考面向使用者，省略这些内容并保留会影响程序含义的规则。二者不一致时以规范为准，并欢迎在 GitHub 上报告。

Scoop 尚未发布正式版本，语言与库仍可能调整。当前支持的目标为 macOS（aarch64-apple-darwin）、Linux（x86_64-unknown-linux-gnu、x86_64-unknown-linux-musl）与 Windows x64（x86_64-pc-windows-msvc-ucrt、x86_64-w64-windows-llvm-mingw-ucrt、x86_64-w64-windows-llvm-mingw-msvcrt），各目标的区别见构建目标，安装方式见快速开始。
