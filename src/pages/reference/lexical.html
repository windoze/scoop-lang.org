词法结构

本章说明 Scoop 源码如何被切分为记号：源文件编码、注释、标识符、关键字和各类字面量。语句与表达式的组合规则见表达式与控制流。

源文件

Scoop 源文件的扩展名为 .scoop，内容必须是合法的 UTF-8 文本。编译诊断按 UTF-8 字节偏移记录位置，再换算为行列号显示。

语句通常每行一条，不需要分号；需要在一行内写多条语句时用 ; 分隔。表达式在仍然缺少右操作数、或仍处于未闭合的括号内时可以跨行：

fun main() {
    val a = 1; val b = 2
    val total = a +
        b
    val sum = add(
        a,
        b
    )
    println(total + sum)
}

fun add(x: Int, y: Int): Int = x + y

参数、实参和数组元素列表不接受尾随逗号；tuple 字面量与 enum 变体列表可以带尾随逗号，其中单元素 tuple 必须写作 (x,)。

解释器行

文件的前两个字节为 #! 时，第一行被当作普通注释，因此单文件程序可以写成脚本形式。它必须位于文件最开头：前面有空白、BOM 或换行时，#! 不再享有此规则。

#!/usr/bin/env -S scoop run
fun main() {
    println("run me directly")
}

注释

  • // … 是行注释，到行尾结束；
  • /* … */ 是块注释，不嵌套：在遇到的第一个 */ 处结束，未终止的块注释是词法错误；
  • /** … */ 与 /// … 是文档注释，附着于紧随其后的声明，由 scoop doc 使用；普通编译把它们当作注释；
  • /*** 开头的块、//// 开头的行以及 //! 都是普通注释。单文件程序头部的 //! dep: group:name:version 用来声明额外依赖，见单文件模式。

字符串与字符字面量内部不识别注释；f-string 插值 ${…} 中的表达式按普通代码处理，可以包含注释。

标识符

标识符以 Unicode XID_Start 字符或 _ 开头，后接任意 XID_Continue 字符，因此可以使用中文等非 ASCII 名称。名称区分大小写，不做 Unicode 规范化。

用反引号包裹的文本是一个完整的标识符，可以包含空格或与关键字同名。反引号内的文本不能为空，不能含反引号、换行或控制字符，也不处理反斜杠转义。`when` 与普通名称 when 的区别只在于不触发关键字语法；`a.b` 是一个名称，而不是两段路径。

fun `check input`(value: Int): Boolean = value >= 0

fun main() {
    val `when` = 1
    val 数量 = 3
    println(`check input`(`when` + 数量))
}

测试库常用反引号把测试函数名写成一句话，见测试库。

关键字

以下是保留关键字，在任何位置都不能直接用作名称（需要时可用反引号）：

as        break     class     continue  do        else      enum
false     for       fun       if        import    in        infix
interface is        package   return    struct    suspend   this
true      val       var       vararg    when      while

其他具有特殊含义的单词是上下文关键字，只在相应的语法位置起作用，例如：

类别上下文关键字
声明object companion typealias constructor init annotation release context
修饰符public internal protected private open final abstract sealed override operator const inner 以及仅为兼容而接受的 inline noinline crossinline reified tailrec
表达式与语句try catch finally throw super case it
属性与约束get set field by where value ref requires

上下文关键字在其他位置可以作为普通名称（例如名为 value 的参数很常见），但在可能产生歧义的表达式位置会被优先解析为关键字语法。Scoop 没有 null 字面量，也没有预定义的 Self 类型；这两个单词只是普通名称。

整数字面量

整数字面量可以写成十进制、0x/0X 十六进制或 0b/0B 二进制，不支持八进制。下划线可以出现在两个数字之间作为分隔，不能位于首尾或紧邻前缀、后缀。

写法类型
42、0xFF、1_000_000无后缀：按上下文期望的有符号整数类型；没有约束时依次取 Int、Long 中第一个能表示该值的类型
42u、0xFFuu/U：按上下文期望的无符号整数类型；没有约束时依次取 UInt、ULong
42Ll/L：固定为 Long
42uL、42ULuL（大小写组合均可）：固定为 ULong
fun main() {
    val a = 42                // Int
    val b = 3_000_000_000     // 超出 Int，推断为 Long
    val c: UInt8 = 255u       // 由期望类型确定为 UInt8
    val d: Int8 = -128        // 负号直接作用于字面量，Int8 的最小值可以表示
    val e = 0b1010_1010uL     // ULong
    println(f"${a} ${b} ${c} ${d} ${e}")
}

字面量的值必须能被最终选定的类型表示，否则是编译错误；无后缀字面量不能适配无符号类型，带 u 的字面量也不能适配有符号类型。十六进制与二进制表示的是非负数学值，不按位模式重新解释：0xFFFFFFFF 不能赋给 Int。字面量的绝对值不能超过 264−1。

fun main() {
    val x: Int8 = 128         // 编译错误：128 不能表示为 Int8
    val y: Int = 5u           // 编译错误：无符号字面量不能用于 Int
}

浮点字面量

浮点字面量必须带有小数部分、指数部分或 f/F 后缀中的至少一项，例如 1.0、.5、1e3、1.5e-2、2f。小数点后必须有数字，因此 1. 不是浮点字面量，1..2 是区间、1.toDouble() 是方法调用。没有十六进制浮点写法，也没有 d/D 后缀。

  • 带 f/F 后缀的字面量类型为 Float；
  • 无后缀的字面量按上下文期望的 Float 或 Double 直接舍入（最近偶数），没有约束时为 Double；
  • 舍入结果为无穷大的有限字面量是编译错误；下溢到次正规数或零是合法的；
  • 负号是一元运算，-0.0 保留负零。整数字面量不会因为期望类型是浮点而变成浮点数，val x: Double = 1 是编译错误。
fun main() {
    val ratio = 0.75          // Double
    val scale: Float = 0.1    // 按 Float 精度直接舍入
    val small = 1.5e-2F       // Float
    println(f"${ratio} ${scale} ${small}")
}

布尔与 Unit

true 与 false 是 Boolean 类型的两个值。() 是 Unit 类型唯一的值，也可以写作 Unit，见 tuple。

字符字面量

字符字面量写在单引号中，转义之后必须恰好是一个 Unicode 标量值，类型为 Char：'A'、'雪'、'😀'、'\u{1F600}'。空字符、多个标量或包含物理换行都是编译错误。字符字面量使用与字符串相同的转义序列。

字符串字面量

普通字符串写在双引号中，类型为 String，支持以下转义：

转义含义
\t \b \n \r制表符、退格、换行、回车
\' \" \\ \$单引号、双引号、反斜杠、美元符号
\uXXXX恰好四位十六进制的 Unicode 标量
\u{X…}一至六位十六进制的 Unicode 标量

每个 Unicode 转义都必须是合法标量值：代理项（U+D800–U+DFFF）、超过 U+10FFFF 的值、缺少数字和未知转义都是编译错误。字符串可以包含 U+0000。

三引号 """…""" 是 raw 字符串：内容原样保留，包括换行，不处理任何反斜杠转义。

fun main() {
    println("tab:\tquote:\" dollar:$ snow:\u{2744}")
    println("""C:\path\no-escape
second line""")
}

f-string 插值

只有以 f 为前缀的字符串支持插值：单行 f"…" 与多行 raw 形式 f"""…"""。插值段写作 ${表达式}，花括号不能省略；$name 是编译错误，编译器会提示改为 ${name}。其他位置的 $ 是普通字符，单行 f-string 中也可以写 \$。普通字符串中的 $ 永远不会触发插值。

fun main() {
    val n = 42
    val price = 9
    println(f"the number is ${n}, next is ${n + 1}")
    println(f"cost: \$${price}")
    println(f"""multi-line
value = ${n * 2}""")
}

插值的语义：

  • 每个插值表达式的类型必须实现 ToString；不存在对任意类型的字符串化回退，自定义类型需要显式实现 ToString。
  • 各段按源码顺序交替求值与转换：前一段的 toString() 完成后才开始求值下一段。任一段抛出异常时，后续段不再求值。
  • 插值中可以调用挂起函数，前提是所在上下文本身允许挂起。
  • 结果等价于用 StringBuilder 依次追加文本与各段结果。插值使用核心库中真实的 ToString 与 StringBuilder，用户同名声明不会改变插值的含义。
  • f-string 不是常量表达式，即使只有文本段也不能用于 const val。

其他字面量

  • 数组字面量 [1, 2, 3] 构造 Array 或 MutableArray，见数组；
  • tuple 字面量 (1, "one")、单元素 tuple (x,)，见 tuple；
  • 没有 null，“无值”用 Option 的 None 表示，见 Option 与空安全；
  • 没有 S { field: value } 形式的 struct 字面量，struct 一律通过构造函数创建。
