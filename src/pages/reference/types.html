类型系统

Scoop 是静态类型语言：每个表达式在编译期都有确定的类型。本章介绍类型的分类、内建的基本类型与数组、类型别名，以及类型检查、转换与推断的规则。用户定义的值类型见 struct、enum 与 tuple，类与接口见类、接口与对象，泛型见泛型。

值类型与引用类型

Scoop 的类型分为两大类：

值类型引用类型
包括struct、enum、tuple，以及 Boolean、整数、浮点、Char、Unit、Ptr 等基本类型class、interface、object、函数类型、Array/MutableArray、String、Any
值完整的数据本身指向堆对象的引用
复制复制全部内容只复制引用，两份引用指向同一对象
identity没有；=== 是编译错误有；=== 比较是否同一对象
可变性构造后不可修改由类型自身决定，例如 var 属性
作为字段或数组元素内联存储，不装箱存储引用

值类型转换为引用类型（Any 或它实现的接口）时自动装箱，见装箱。引用类型的对象由垃圾回收器管理，不需要也不能手动释放；文件、套接字等原生资源用 use 确定性地关闭。

参数传递

所有函数调用都按值传递：每个实参求值一次，用所得的值初始化被调函数中不可重新赋值的形参。值类型传递的是完整副本；引用类型传递的是引用的副本，因此调用双方看到同一个对象，通过它做的修改彼此可见，但在函数内给形参赋值是编译错误，也不会影响调用方的变量。方法的接收者 this 同样按值传递：值类型方法中的 this 是接收者的局部副本。

Any 与 Nothing

Any 是所有类型的根类型，包括值类型。与 Kotlin 不同，Any 没有任何成员：没有 equals、toString 或 hashCode。相等、字符串化和哈希分别由 Equals<T>、ToString、Hash 等接口提供，类型需要显式实现它们，见运算符与相等。因此静态类型为 Any 的两个值不能用 == 比较，也不能直接打印。

Nothing 是所有类型的子类型，没有任何值。类型为 Nothing 的表达式不会正常完成，例如 throw、return、break、continue 以及返回类型为 Nothing 的函数调用。Nothing 分支不参与结果类型的合并，因此可以出现在任何需要值的位置：

fun fail(message: String): Nothing = throw IllegalStateException(Some(message))

fun parsePort(text: String): Int {
    val port = if (text == "http") 80 else fail(f"unknown scheme ${text}")
    return port
}

fun main() {
    println(parsePort("http"))
}

声明返回 Nothing 的函数不能正常结束或执行 return。Nothing 不同于 Unit：Unit 有唯一的值 ()，表示“正常完成但没有有意义的结果”。

整数宽度在所有目标上都是固定的：Int 永远是 32 位，Long 永远是 64 位，Scoop 没有随平台变化的整数类型。别名是透明的：Int32 与 Int 是同一类型，不能用来形成不同的重载。

除 String 外，基本类型都是值类型。它们都实现了 Equals（同类型比较）与 ToString；Boolean、Char、整数和 String 还实现了 Hash，浮点数不实现 Hash。

整数

运算

二元算术、位运算与比较要求两个操作数是同一个整数类型。不同宽度或符号的整数之间不做隐式提升，需要显式转换；字面量可以直接适配另一侧的类型：

fun main() {
    val count: Int = 3
    val total: Long = 10L
    val sum = total + count.toLong()   // 显式转换为 Long
    val next = total + 1               // 字面量 1 直接取 Long
    println(f"${sum} ${next}")
}
fun main() {
    val a: Int = 1
    val b: Long = 2L
    println(a + b)    // 编译错误：Int 与 Long 不能直接相加，需要 a.toLong()
}
  • +、-、*、一元 -、++/-- 按位宽回绕（二进制补码），溢出不抛异常：Int.MAX_VALUE + 1 == Int.MIN_VALUE。无符号类型同样支持一元 -，-1u 等于 UInt.MAX_VALUE。
  • / 向零截断，% 的结果与被除数同号：-7 / 2 == -3，-7 % 2 == -1。除数为零时抛出 ArithmeticException；MIN_VALUE / -1 结果为 MIN_VALUE，不抛异常。
  • 位运算是普通的 infix 方法而不是运算符：and、or、xor、inv()、shl、shr，有符号类型另有逻辑右移 ushr。移位次数的类型固定为 Long，只取低 log2(位宽) 位；有符号 shr 是算术右移，无符号类型的 shr 是逻辑右移。
  • 比较按数学上的有符号或无符号次序；compareTo 返回 Long 类型的 -1L、0L 或 1L。
  • 需要溢出检查的算术请使用 scoop.math 提供的受检运算，见库 Cone 一览。
fun main() {
    println(1 shl 3)            // 8
    println((-16) shr 2)        // -4
    println(0xF0 and 0x3C)      // 48
    println(5.inv())            // -6
    println(Int.MAX_VALUE + 1)  // -2147483648
}

转换与常量

每种整数都提供到八种整数的显式转换 toByte()、toShort()、toInt()、toLong()、toUByte()、toUShort()、toUInt()、toULong()，以及 toFloat()、toDouble()。整数之间的转换总是成功：源值对 2目标位宽 取模后按目标的符号解释，例如 300.toByte() == 44，(-1).toUInt() == 4294967295u。到浮点的转换按目标精度舍入到最近值。

每种整数的 companion 提供 MIN_VALUE 与 MAX_VALUE 常量。整数的 toString() 产生与区域设置无关的十进制文本。

浮点数

Float 与 Double 承载 IEEE 754 binary32 / binary64 的全部值，包括次正规数、正负零、无穷大和 NaN。两者之间、它们与整数之间都不做隐式转换。

运算与转换

  • + - * / 按目标精度最近偶数舍入。除以零、无效运算和溢出产生 IEEE 结果（无穷大或 NaN），不抛异常。编译器不会重结合运算或自动合并乘加。
  • % 是以向零截断的商定义的余数（与 C 的 fmod 相同），不是 IEEE remainder：7.5 % 2.0 == 1.5。
  • 浮点到整数的转换向零截断，越界时饱和到目标类型的最小或最大值，NaN 转为 0：1e20.toInt() == Int.MAX_VALUE，(-5.0).toUInt() == 0u。
  • Float 到 Double 是精确的；Double 到 Float 按最近偶数舍入。

比较

浮点的 == 与 compareTo 使用一个全序，使浮点数可以安全地用作排序键和模式：

输入==compareTo
两个 NaN（任意符号与 payload）true0
左侧 NaN，右侧非 NaNfalse1（NaN 排在 +∞ 之后）
-0.0 与 +0.0true0
其他值数值相等数值次序

这与 IEEE 比较不同：x != x 不能用来检测 NaN，请使用 isNaN()。需要 IEEE 语义时调用 ieeeCompare(other)，它返回 IeeeComparison 的 Less、Equal、Greater 或 Unordered，任一操作数为 NaN 时为 Unordered。比较只做分类，不改写数值：1.0 / -0.0 仍是负无穷。

fun main() {
    val nan = 0.0 / 0.0
    println(nan == nan)                                        // true
    println(nan.isNaN())                                       // true
    println(nan.ieeeCompare(nan) == IeeeComparison.Unordered)  // true
    println(-0.0 == 0.0)                                       // true
}

常量、位表示与文本

  • companion 常量：NaN、POSITIVE_INFINITY、NEGATIVE_INFINITY、MAX_VALUE（最大有限值）、MIN_VALUE（最小正次正规数）、MIN_NORMAL（最小正规格化数）。
  • 分类方法：isNaN()、isInfinite()、isFinite()。
  • Float.toBits(): Int / Float.fromBits(bits)，Double.toBits(): Long / Double.fromBits(bits) 按位重新解释，保留 NaN payload 与零的符号。
  • toString() 输出能按原精度读回相同值的最短十进制数字，与区域设置无关：十进制指数在 [−3, 7) 内用定点（1234567.0、0.001），否则用科学记数法（1.0e7、1.0e-4）；总是带小数点，特殊值为 NaN、Infinity、-Infinity，负零为 -0.0。
  • 浮点数没有 Hash 实现，也没有浮点区间类型。数学函数（sqrt、三角函数等）由 scoop.math 提供。

Char

Char 表示一个 Unicode 标量值（U+0000–U+D7FF 或 U+E000–U+10FFFF），不是 UTF-16 码元，也不是用户感知的字素簇。它以 32 位存储，与整数之间没有隐式转换，也没有算术运算。

  • c.code: Int 返回标量编号；n.toChar() 把 Int 转为 Char，编号不合法时抛出 IllegalArgumentException；
  • 比较与相等按标量编号进行，toString() 返回只含该字符的字符串；
  • Char 实现 Hash，可以作为哈希表的键，也可以用于 const val 和模式。

String

String 是不可变的引用类型，保存合法的 UTF-8 文本，可以包含 U+0000。+ 拼接两个字符串，==、比较与哈希都按内容进行；比较是按 Unicode 标量的字典序。

字符串不支持下标 s[i]，也没有 length 属性，以区分常数时间的字节计数与需要扫描的字符计数：

fun main() {
    val s = "A雪😀"
    println(s.charLength)        // 3：Unicode 标量的个数，需要扫描
    println(s.byteLength)        // 8：UTF-8 字节数，O(1)
    println(s.getCharAt(1L))     // 雪
    println(s.slice(1L, 3L))     // 雪😀
    for (c in s) print(c)        // String 实现 Iterable<Char>
    println("")
}

字符计数与下标都使用 Long，越界时抛出 IndexOutOfBoundsException。字符串不做 Unicode 规范化，"e\u0301" 与 "\u00E9" 不相等。完整的字符串 API 见核心库，查找、分割、替换、数值解析等文本操作由 scoop.text 提供。

数组

核心库提供两种定长数组，它们都是引用类型：

  • Array<T>：长度固定，元素不可写；
  • MutableArray<T>：长度固定，元素可写。

元素为值类型时，数组保证元素不装箱、连续存放。两种数组都实现只读的 List<T>，因此可以用 for 遍历；长度可变的列表请使用 ArrayList<T>。

数组字面量

[e1, e2, …] 构造一个新数组。构造 Array 还是 MutableArray 由上下文的期望类型决定，没有约束时为 Array。空数组 [] 必须有期望类型。

  • 有期望类型时，每个元素都必须是期望元素类型的子类型。
  • 没有期望类型时，若任一元素是值类型，其余元素的类型必须与它完全相同；若全部是引用类型，元素类型取它们的最小共同上界，没有唯一上界时取 Any（编译器给出警告）。
  • 数组字面量中的值类型元素不会自动装箱，需要放进接口数组时显式写 as。
interface Shape {}
struct Square(val side: Int) : Shape

fun main() {
    val numbers = [1, 2, 3]                       // Array<Int>
    val scores: MutableArray<Int> = [90, 85]      // MutableArray<Int>
    val shapes: Array<Shape> = [Square(1) as Shape, Square(2) as Shape]
    val none: Array<String> = []
    println(numbers.size + scores.size + shapes.size + none.size)
}

操作

  • a[i] 读取元素，m[i] = v 写入 MutableArray 的元素；下标类型是 Long，越界抛出 IndexOutOfBoundsException。
  • size: Long 是元素个数。
  • Array<T>(size) { index -> … } 与 MutableArray<T>(size) { … } 按长度构造，依次以 0L 到 size - 1L 调用初始化函数；size 为负时抛出 IllegalArgumentException。
  • Array 与 MutableArray 之间没有子类型关系，用 m.toArray()、a.toMutableArray() 或构造函数 Array(m)、MutableArray(a) 复制转换，结果是独立的新数组。
  • 数组与其他泛型类型一样是不变的：即使 Circle 是 Shape 的子类型，Array<Circle> 也不是 Array<Shape>。
  • 数组没有结构相等，不实现 Equals 与 ToString。
fun main() {
    val squares = Array<Long>(4L) { i -> i * i }
    val buffer: MutableArray<Int> = [0, 0, 0]
    buffer[1] = 7
    val snapshot = buffer.toArray()
    buffer[1] = 8
    println(f"${squares[3]} ${snapshot[1]} ${buffer[1]}")   // 9 7 8
}

函数类型

函数类型写作 (P1, P2) -> R，挂起函数类型写作 suspend (P1) -> R，带接收者的函数类型写作 A.(P) -> R。函数类型是引用类型；参数逆变、返回值协变；普通与挂起函数类型之间不能转换。详见函数与闭包。

Option

T? 是核心库 enum Option<T> { Some(T), None } 的写法，Scoop 在运行期没有 null。T?? 是 Option<Option<T>>，与 T? 是不同的类型。见 Option 与空安全。

类型别名

typealias 为已有类型引入另一个名称。别名是透明的：它不创建新类型，与展开后的类型完全等价，不能据此区分重载。别名可以带类型参数，也可以声明在类型内部或代码块中：

public typealias UserId = ULong
typealias Names<T> = Array<T>
typealias Transform<T> = (T) -> T

fun twice(f: Transform<Int>, x: Int): Int = f(f(x))

fun main() {
    typealias Point = (Int, Int)
    val origin: Point = (0, 0)
    val names: Names<String> = ["Ada", "Lin"]
    val id: UserId = 42u
    println(twice({ it + 1 }, origin._1) + names.size.toInt() + id.toInt())
}
  • 在类型位置使用泛型别名时必须给出全部类型参数；构造调用 Alias(…) 可以像普通构造一样推断。
  • 别名的展开不能直接或间接引用自身。
  • 顶层别名默认 internal，不能借别名公开一个不可见的类型；局部别名不能带可见性修饰符，只在声明之后的块内可见。

类型检查与转换

表达式含义
e is T / e !is T运行期检查 e 的实际值是否属于 T
e as T转换为 T；失败时抛出 ClassCastException
e as? T转换为 T?；成功为 Some(值)，失败为 None
  • 值类型向引用类型的 as（如 s as Shape）会装箱；对装箱值使用 is/as 可以取回原来的值类型。
  • 泛型没有类型擦除，检查目标必须写出完整的类型实参：x is Box<Int> 与 x is Box<String> 是不同的检查，没有 Box<*>。
  • 函数类型按参数逆变、返回协变的结构关系检查。
  • enum 的变体不是类型，不能出现在 is 右侧；判断变体请用 when 模式。
struct Box<T>(val value: T)

fun main() {
    val boxed: Any = Box(1)
    println(boxed is Box<Int>)       // true
    println(boxed is Box<String>)    // false
    val text: String? = boxed as? String
    println(text == None)            // true
}

smart cast

经过 is 检查后，编译器在检查成立的路径上把变量当作更具体的类型使用，无需再写 as。类型事实沿实际执行路径传播：&&、||、! 分别建立真、假路径上的事实；return、throw、break、continue 之后的代码只考虑没有跳转的路径。

fun describe(x: Any): String {
    if (x !is String) return "not text"
    return f"text of ${x.charLength} chars"     // 这里 x 被视为 String
}

fun main() {
    var value: Any = "hello"
    if (value is String && value.charLength > 3L) println(describe(value))
    value = 42                                   // 赋值撤销此前的类型事实
    if (value is Int) println(value + 1)
}
  • 可以收窄的对象：不可变局部变量、参数、when subject 的 val 绑定、模式绑定，以及当前函数内的局部 var（每次重新赋值都会撤销旧的事实）。
  • 属性、带自定义 getter 或委托的值每次读取都可能变化，不会被收窄；需要稳定视图时先存入局部 val，或使用 when (val x = expr)。
  • 多个分支合并时只保留各路径共同成立的事实；循环中的事实对所有迭代都成立才保留。
  • as / as? 只产生转换结果，不会让原变量在之后被收窄。
  • Option 没有判空收窄：判断 x != None 之后 x 仍是 T?，取值请用 when、?: 或 !!，见 Option。

类型推断

  • 局部变量：val x = expr 的类型就是 expr 的类型。
  • 函数结果：表达式体函数 fun f() = expr 省略结果类型时从表达式推断；块体函数省略结果类型时结果为 Unit。递归函数需要显式结果类型来打断推断环。
  • 属性：非局部属性可以从初值、表达式 getter 或委托推断类型；没有这些来源的属性必须写类型。
  • 分支合并：if、when、try 作为值时，有期望类型则每个分支都必须适配它；否则取各正常分支的最小共同上界，存在多个互不可比较的上界时退化为 Any。泛型类型只有类型实参完全相同时才合并为同一个 application，Box<Int> 与 Box<Long> 不会合并成 Box<某个上界>。
  • 泛型调用：类型实参由全部实参与期望类型共同推断，可以用 _ 只写出其中一部分，见泛型。
  • 推断不会把无法确定的类型猜成 Any 或 Unit：空数组、没有期望类型的 None 和参数类型未知的 lambda 需要显式标注。
