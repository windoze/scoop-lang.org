struct、enum 与 tuple

Scoop 有三种用户可用的值类型：命名的积类型 struct、带载荷的和类型 enum，以及匿名的 tuple。它们都不可变、没有 identity，复制时复制完整值，作为字段或数组元素时内联存储。

struct

struct 在主构造函数中声明字段。字段只能用 val 声明，可以有默认值；构造时可以使用位置参数和命名参数：

struct Config(val host: String, val port: Int = 8080, val secure: Boolean = false)

fun main() {
    val local = Config("localhost")
    val prod = Config(host = "example.com", port = 443, secure = true)
    println(f"${local.host}:${local.port} ${prod.secure}")
}
  • struct 构造完成后不可修改。var 字段、init 块都是编译错误。
  • 字段不能写可见性修饰符，固定为 public，但实际可见范围不超过 struct 本身：默认 internal 的 struct，其字段也不会对其他 Cone 可见。
  • struct 不能继承其他类型，也不能被继承，但可以实现接口。
  • body 中可以声明成员函数、计算属性 val p: T get() = … 和 companion object，不能有存储属性或委托属性。
  • 没有 S { field: value } 形式的字面量，struct 只能通过构造函数创建。

次构造函数

struct 可以在 body 中声明次构造函数。次构造函数的参数不声明字段（不能写 val），必须用 this(…) 直接或间接委托到主构造函数。委托先构造出完整的值，再由内向外执行各次构造函数的 body；body 可以读取字段、执行同步操作或抛出异常，但不能修改字段或 return。任一步抛出异常时不产生值。

struct NonEmpty(val text: String) {
    constructor() : this("default") {}
    constructor(count: Int) : this("x") {
        if (count <= 0) throw IllegalArgumentException(Some("count must be positive"))
    }

    val length: Long get() = text.charLength

    companion object {
        fun of(text: String): NonEmpty = NonEmpty(text)
    }
}

fun main() {
    println(NonEmpty().text)
    println(NonEmpty(3).length)
    println(NonEmpty.of("abc").length)
}

enum

enum 定义带载荷的代数数据类型，取代 Kotlin 的 enum class 与大部分 sealed class 用法。每个变体可以采用以下形式之一：

enum Message {
    Quit,                                          // 单元变体
    Move(Int, Int),                                // 位置载荷
    Write { text: String, urgent: Boolean },       // 命名字段
    Resize(val width: Int, val height: Int = 1)    // 构造函数式命名字段，可带默认值
}

fun main() {
    val all = [
        Message.Quit,
        Message.Move(1, 2),
        Message.Write(text = "hi", urgent = false),
        Message.Resize(10),
        Message.Resize(width = 3, height = 4)
    ]
    println(all.size)
}
  • 每个变体都是一个构造器：单元变体直接写 E.V，带载荷的变体像函数一样调用。
  • 花括号形式的命名字段变体只能用命名参数构造；构造函数式变体与 struct 主构造函数规则相同，可以用位置参数、命名参数和默认值。两者都没有花括号构造写法。
  • 变体和字段的可见性固定为 public（不超过 enum 本身的可见范围）。
  • enum 本身没有构造函数、init 块或存储状态；body 中可以声明成员函数、计算属性 val 和 companion object。成员声明位于变体列表之后。
  • enum 可以实现接口，可以是泛型的，例如核心库的 enum Option<T>。
enum Shape {
    Circle(Double),
    Rect { width: Double, height: Double }

    val isRound: Boolean get() = when (this) {
        case Circle(_) -> true
        case Rect { .. } -> false
    }

    fun area(): Double = when (this) {
        case Circle(r) -> 3.14159 * r * r
        case Rect { width, height } -> width * height
    }
}

fun main() {
    val s = Shape.Rect(width = 2.0, height = 3.0)
    println(f"${s.area()} ${s.isRound}")
}

变体不是类型

变体只是构造器，不能用作变量类型、参数类型或 is 的检查目标。判断一个值属于哪个变体、提取载荷，都通过 when 的 case 模式完成。模式中可以省略 Shape. 前缀，由被匹配值的类型确定。

省略 enum 前缀

在表达式中，下列情况可以直接写变体名：

  • 期望类型唯一确定为某个 enum（如 val s: Shape = Circle(1.0)、返回值、实参位置），编译器只在该 enum 内查找同名变体；
  • 用 import Shape.* 导入了变体。核心库的 Option 就是这样默认导入的，所以可以直接写 Some 与 None。

普通的局部变量、导入和声明优先于这种按期望类型的查找。期望类型是 Any、接口或尚未确定时，必须写出 E.V 或补充类型标注。

enum Level { Low, High }

fun pick(urgent: Boolean): Level = if (urgent) High else Low

fun main() {
    val level: Level = Low
    println(pick(true) == Level.High)
    println(level == Level.Low)
}

整型枚举

enum E: I { … } 声明以整数类型 I 为父类型的整型枚举，I 必须是八种整数类型之一。每个变体必须写出显式的值，不能携带载荷，也不会按声明顺序自动编号；值必须是常量表达式、能被 I 表示，且同一 enum 中不能重复。

enum HttpStatus: Int {
    Ok = 200,
    NotFound = 404,
    Teapot = 418
}

fun main() {
    val status = HttpStatus.NotFound
    val code: Int = status          // 按值上转为 Int，不分配
    println(code + 1)               // 405
    println(status + 1)             // 运算使用 Int 的成员，结果是 Int
}
  • E 是 I 的子类型，可以隐式上转为 I；I 不能转回 E，即使数值恰好等于某个变体。
  • 整型枚举使用 I 的运算与接口，结果类型是 I：e + 1 是 Int，e += 1 与 e++ 因无法写回 E 而是编译错误。
  • 以 E 为 subject 的 when 列出全部变体即可穷尽。
  • 它与 I 有相同的大小和 C ABI，可以直接用于 FFI 与注解参数。外部代码只能传入已声明的值；可能出现未知数值的接口应声明为底层整数类型。

tuple

tuple 是匿名的积类型，无需声明。类型写作 (T1, T2, …)，字面量写作 (e1, e2, …)：

fun divmod(a: Int, b: Int): (Int, Int) = (a / b, a % b)

fun main() {
    val pair = (1, "one")              // (Int, String)
    val single = (42,)                 // 单元素 tuple，类型 (Int,)
    val nothing: Unit = ()             // 零元素 tuple 就是 Unit
    val (q, r) = divmod(17, 5)
    println(f"${pair._2} ${single._1} ${q} ${r}")
}
  • () 是 Unit；(e) 是带括号的表达式 e 本身；(e,) 是单元素 tuple；两个以上元素用逗号分隔。
  • 元素通过解构或位置访问 t._1、t._2……（从 _1 开始）读取。
  • 全部元素可比较时，tuple 支持结构相等 ==。
  • tuple 不能声明实现接口，也不实现 ToString，因此不能直接打印或插值。需要这些能力时，用命名 struct 代替。

值类型的通用规则

不可变性与 identity

值类型实例构造后不能修改。要得到修改后的值，对 struct 使用副本更新，对 enum 与 tuple 重新构造；把新值赋给 var 是重新绑定变量，不是原地修改。

值类型没有 identity：对值类型使用 === 或 !== 是编译错误，比较请用 ==。

实现接口

struct 与 enum 可以实现接口，实现的成员必须写 override；覆写 public 接口成员（例如 ToString.toString）时还要写 public，因为成员默认是 internal。值类型的方法总是 final。接口若要求可写属性（var），值类型不能实现它。

interface Describable {
    fun describe(): String
}

struct Point(val x: Int, val y: Int) : Describable, ToString {
    override fun describe(): String = f"point at ${x},${y}"
    public override fun toString(): String = f"(${x}, ${y})"
}

fun main() {
    val p = Point(1, 2)
    val d: Describable = p      // 装箱
    println(d.describe())
    println(p)
}

装箱

值类型转换为引用类型（Any 或实现的接口）时自动装箱为堆对象。装箱后的对象不可变、具有 identity，== 按装箱后的静态类型查找 equals。用 is、as、as? 或模式可以取回原来的值。

自动装箱只发生在单个值的转换上：赋值、实参、返回值等。数组字面量这类批量位置不会自动装箱，需要对每个元素显式写 as，见数组字面量。

副本更新

base.{ field: expr, … } 基于一个已有的 struct 值创建修改了部分字段的新值，原值不变：

struct Settings(val width: Int, val height: Int, val title: String)

fun main() {
    val base = Settings(800, 600, "untitled")
    val wide = base.{ width: 1920, title: "wide" }
    var current = base
    current = current.{ height: 720 }     // 重新绑定 var，不是原地修改
    println(f"${wide.width}x${wide.height} ${current.height} ${base.height}")
}
  • base 先求值且只求值一次，其静态类型必须正好是某个 struct；enum（即使是命名字段变体）、class、tuple 都不支持副本更新。
  • 字段列表不能为空，字段名不能重复，也不能写嵌套路径；各右侧表达式按书写顺序求值，未提及的字段从 base 复制。
  • 没有穿透 Option 的 opt?.{ … }，请先用 when 或 ?. 取出 struct。

解构

val/var 声明、for 循环变量和 lambda 参数都可以使用解构模式，一次绑定多个名称。解构模式必须对静态类型不可失败：可以包含名称、_、.. 以及嵌套的 tuple/struct 模式，不能包含字面量或 enum 变体（这些可能失败的模式只能用在 when 中）。

struct User(val id: Long, val name: String, val email: String)

fun main() {
    val user = User(1L, "Ada", "ada@example.com")
    val (id, name, _) = user                    // 按字段顺序
    val User { email, .. } = user               // 按字段名，.. 忽略其余字段
    val User { name: displayName, .. } = user   // 重命名
    val (first, .., last) = (1, 2, 3, 4)        // .. 跳过中间元素
    val (n, (a, b)) = (7, ("x", "y"))           // 嵌套
    println(f"${id} ${name} ${email} ${displayName} ${first + last} ${n}${a}${b}")

    for ((index, word) in [(1, "one"), (2, "two")]) {
        println(f"${index}: ${word}")
    }
    val add: ((Int, Int)) -> Int = { (x, y) -> x + y }
    println(add((3, 4)))
}
  • 位置模式 (p1, p2, …) 适用于 tuple 与 struct（按主构造函数的字段顺序）。不使用 .. 时元素个数必须一致。
  • 字段模式 S { f1, f2: p, .. } 适用于 struct。f1 是 f1: f1 的简写；冒号右侧可以是新名称、_ 或嵌套模式。未列出全部字段时必须以 .. 结尾；类型前缀 S 可以省略。
  • .. 在位置模式中至多出现一次，可以位于开头、中间或结尾，表示忽略任意多个元素；在字段模式中只能位于末尾。
  • 普通 class 与接口可以通过 operator fun component1()、component2()……支持位置解构（不能使用 ..），见运算符。struct 与 tuple 的解构是内建的，不查找 componentN。
  • 被解构的值只求值一次；var 解构声明中只有叶子名称是可变的。
  • 在解构模式中，单独的标识符总是新绑定，即使它与某个 enum 变体同名。
fun main() {
    val maybe: Int? = Some(1)
    val Some(x) = maybe      // 编译错误：可能失败的模式只能用于 when
}

lambda 参数使用解构模式时，参数类型由期望的函数类型提供，如上例的 add。

结构相等

struct、enum 和 tuple 在全部字段（或元素、当前变体的载荷）都可以比较时，自动获得同类型的 ==：struct 与 tuple 按声明顺序逐个比较并短路；enum 先比较变体，再比较载荷。浮点字段沿用浮点的默认相等。

  • 自动生成的只有 == 运算符，类型不会因此实现 Equals<T> 接口；需要作为 HashMap 键或满足 T : Equals<T> 时，显式声明并实现该接口。
  • 字段不可比较（例如某个 class 字段没有 equals）时，构造和传递不受影响，只有实际使用 == 的地方会报错。
  • 手写同签名的 operator fun equals(other: S): Boolean 会取代自动生成的比较。
  • ToString 与 Hash 从不自动派生，需要显式实现，见运算符与相等。

零大小类型

Unit、没有字段的 struct，以及所有字段都是零大小类型的 struct 或 tuple，大小都为 0。它们仍是各自独立的类型，构造和调用的副作用照常执行；Array<Unit> 等数组不分配元素存储，但长度与下标检查保持不变。
